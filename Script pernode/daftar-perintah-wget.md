# Perintah Download Script per Node (Online dari GitHub)

Cara pakai: buka console node yang bersangkutan di GNS3 (klik dua kali node-nya), copy-paste satu baris perintah di bawah nama node tersebut, lalu Enter.

Alamat dasar file di GitHub:
`https://raw.githubusercontent.com/Kangproo/Jarkom-Modul-4-2026-K-09/main/Script%20pernode`

## Catatan Penting

1. **Cyberia duluan.** Router Cyberia terhubung langsung ke internet lewat NAT1, jadi dia bisa langsung mengunduh. Setelah script Cyberia dijalankan (NAT sudah aktif), barulah node lain punya jalan keluar ke internet.
2. **Node lain butuh jalur ke internet yang sudah aktif.** Sebelum bisa `wget`, sebuah node harus sudah punya IP dan rute menuju internet. Masalahnya, pengaturan IP dan rute itu justru ada di dalam script yang mau diunduh. Jadi untuk node selain Cyberia, cara paling praktis adalah:
   - atur IP dan default route-nya secara manual dulu (beberapa baris), baru `wget` seperti di atas, atau
   - gunakan cara klasik: copy isi script dari laptop, paste ke console node, lalu Enter.
3. **Kalau `wget` belum terpasang** di node:
   ```bash
   apt-get update && apt-get install -y wget
   ```
   Atau ganti `wget -O` dengan `curl -o` pada perintah di atas.
4. **Kalau gagal dengan pesan kesalahan nama domain (DNS)**, isi DNS dulu:
   ```bash
   echo "nameserver 8.8.8.8" > /etc/resolv.conf
   ```
5. **Pastikan repository tetap publik.** Kalau repository diubah menjadi private atau file-nya dipindahkan, alamat di atas tidak akan berlaku lagi.
